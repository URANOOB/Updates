# Guía de contribución

## Entradas diarias

1. Crea el archivo `diario/AAAA-MM-DD.md`.
2. Describe un avance, aprendizaje o nota técnica concreta.
3. Si no hubo novedades materiales, registra la revisión de continuidad sin inventar resultados.
4. Usa un mensaje de commit breve que explique el cambio.

## Formato recomendado

Incluye una sección de avance o revisión, el estado actual y, cuando aplique, el siguiente paso técnico.

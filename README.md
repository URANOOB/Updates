# Updates

Bitácora personal de avances, aprendizajes y notas técnicas.

## Estructura

- `diario/`: una entrada Markdown por cada revisión diaria.

## Criterio de contenido

Las entradas describen avances concretos cuando existen. En días sin novedades técnicas materiales se registra la revisión de continuidad de forma explícita, sin inventar resultados.
